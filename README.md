# Projeto Fourdex
Repositório criado para organização e criação da Pokedéx solicitado pela Uniamérica.
Um sistema desenvolvido para facilitar a procura de informações de pokémons.


## Como executar?
1.  Abra a pasta com os arquivos deste sistema.
2.  Dê um clique-duplo no arquivo nomeado index.html

## Funcionalidades
- Aba de pokémons contendo todos os pokémons que existem.
- Informações detalhadas sobre cada pokémon.
- Sistema de pastas para organização de pokémons salvos.
- Layout intuitivo e com guias para entender as opções.
- Sistema de login para salvamento de dados.
