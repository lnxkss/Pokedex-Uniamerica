# Fourdex - Pokédex

A **Fourdex** é uma Pokédex desenvolvida como projeto acadêmico do curso de Análise e Desenvolvimento de Sistemas (ADS) da UniAmérica.

O objetivo do projeto é criar um site onde os usuários possam pesquisar Pokémons, visualizar suas informações e navegar entre diferentes espécies, utilizando dados direto da PokéAPI.

## Funcionalidades

- Listagem de Pokémons com nome, imagem e número da Pokédex.
- Pesquisa de Pokémons pelo nome.
- Carregamento de 20 Pokémons por vez, com opção de carregar mais.
- Página de detalhes com informações como tipos, altura, peso e atributos.
- Visualização das versões normal e Shiny dos Pokémons.
- Visualização de diferentes formas e variantes.
- Navegação entre Pokémons pelos botões de anterior e próximo.
- Armazenamento da última pesquisa utilizando LocalStorage.
- Responsividade no layout para diferentes tamanhos de tela.

O projeto também tem interfaces de perfil, cadastro, login e organização de Pokémons em pastas, que ainda estão em desenvolvimento.

## Tecnologias utilizadas

**HTML5:** estrutura das páginas.
**CSS3:** estilização, layout, responsividade e animações.
**JavaScript:** funcionalidades, manipulação do DOM e integração com a API.
**LocalStorage:** armazenamento de informações no navegador.
**PokéAPI:** fornecimento dos dados dos Pokémon.

## Como executar

1. Baixe ou clone este repositório.
2. Abra a pasta do projeto.
3. Clique duas vezes no arquivo "home.html".

Você precisa estar conectado a internet para conseguir acessar o site.

## Sobre o projeto

A Fourdex foi desenvolvida ao longo do segundo período do nosso grupo na faculdade UniAmérica.

O projeto busca colocar em prática conceitos de desenvolvimento web, uso de APIs, manipulação dinâmica de elementos, armazenamento local e criação de interfaces com responsividade.

## API utilizada

Os dados dos Pokémon são fornecidos gratuitamente pela [PokéAPI](https://pokeapi.co/).
